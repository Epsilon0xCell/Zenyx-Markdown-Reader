# Security Policy

## Reporting a vulnerability

If you find a security issue in this project, please report it privately before disclosing it publicly.

The preferred route is GitHub private vulnerability reporting on this repository: the Report a vulnerability button under the Security tab. That keeps the report between you and me until a fix is ready.

If private reporting is unavailable, open a public issue that says only that you have a security report and need a private contact route. Do not include details, proof of concept code, or affected versions in a public issue.

## What to expect

I read every report myself. I will confirm receipt, verify the issue against the current release, and credit the reporter in the published advisory when a fix ships, unless the reporter asks to stay anonymous.

## Supported versions

Only the latest state of the default branch receives security fixes.
